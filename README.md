# House B 3D model viewer

Read-only 3D model of House B, Set Rev 48 (model v92), for bidders and trades.

**Open it:** https://jimsturdevant.github.io/house-viewer/ (works on computers and phones), or download `index.html` and open it in any current browser. It needs no install or account and works offline.

**Use it:** Orbit / Walk at the top. In Walk, drag to look, W/A/S/D or the arrows to move, or tap the on-screen arrows on a phone; double-click goes to a spot. Click an item to see its size and sheet references, and use Measure, Section cuts and the Find box in the left panel. Press **?** for all the controls.

**Drawings:** select an item and use the orange "open" tag next to a sheet number to see that drawing sheet. These are a public reference copy (owner, designer and site information withheld; not for construction) and need a PIN from the owner.

**What governs:** the sealed PDF construction set. MEP routing in the model is schematic; the trade layouts govern. The model is updated with every published design revision; this page shows Set Rev 48.
